## 🔴 CRITICAL（必须修复）

### 1. DataBridge.Start() 重复订阅 OnDataChanged → 数据重复投递
**文件**: `DataBridge.cs:207` / `314`  
**问题**: `Start()` 每次调用都 `+=` 事件，`Dispose()` 只 `-=` 一次。若网关重启未 Dispose 旧实例，或 Start/StartAsync 混用，每个 DA 回调触发 N 次投递。  
**修复**:
```csharp
_daClient.OnDataChanged -= OnDaDataChanged;
_daClient.OnDataChanged += OnDaDataChanged;
```

### 2. OpcDaClient.AddAllItems() 批量重建字典 O(n²) + 锁竞争
**文件**: `OpcDaClient.cs:295-323`  
**问题**: 35k 循环中对 `List<string>` 逐 tagKey `lock(list)` + `Add`，同一 ItemId 多 tagKey 竞争严重，且 `List.Add` 为 O(n)。  
**修复**: 启动期本地构建字典，锁内原子替换引用（见报告正文代码示例）。

### 3. DataBridge.StartAsync() _uaServer 快照为 null 竞态
**文件**: `DataBridge.cs:241, 297-298`  
**问题**: 并发 StartAsync/StopAsync 时，Stop 可能在 Task.Run 循环结束后、访问 VariableCount 前将 `_uaServer` 置 null。  
**修复**: L297-298 加 `uaServer?.VariableCount ?? 0` / `uaServer?.NamespaceIndex ?? 0`。

## 🟠 HIGH（高风险）

### 4. OpcDaClient 回调异常日志放大攻击
**文件**: `OpcDaClient.cs:373-376` / `450-451`  
**风险**: 单次批量回调 1000+ 点位同时异常 → 瞬间触发 1000+ 条 `OnStatusChanged` → UI 日志队列雪崩。  
**修复**: 批次内限流（仅记首条 + 计数）。

### 5. OpcDaClient.Cleanup() 超时分支排队永久挂起工作项
**文件**: `OpcDaClient.cs:477-489`  
**风险**: `int.MaxValue` ms (24.8 天) 等待实际上永不超时；每次重连/停止新增挂起工作项 → 线程池耗尽；最终执行可能释放错误 COM 对象。  
**修复**: 有界等待 30s + 代际校验。

### 6. MainForm.GatewayStopRequested fire-and-forget Task 异常未观察
**文件**: `MainForm.cs:839-842`  
**风险**: `.NET Framework 4.7.2` 下未观察 Task 异常在 GC/Finalizer 抛出，可能终止进程。`handleTrialExpiredAsync` 含 `MessageBox.Show`/`Close()` 等可能抛异常调用。  
**修复**: 显式异常处理的 `Task.Run` 包装。

### 7. Program.cs 异常处理器空 catch 掩盖 MessageBox 二次崩溃
**文件**: `Program.cs:82-88`  
**风险**: `MessageBox.Show` 在 UI 不一致状态抛异常被完全吞掉，崩溃日志写入失败后无用户可见反馈。  
**修复**: 至少记录到 Debug/EventLog。
